# 侯瑞 AI 个人档案

> 用于让 AI 工具、合作伙伴和未来的自己快速理解：我是谁、擅长解决什么问题、如何协作，以及哪些边界不能越过。

## 01. 我是谁

- 称呼：侯瑞
- 当前定位：现实问题解决型创作者与项目推动者
- 长期角色：把复杂、混乱、信息不完整的现实问题，拆成看得清、排得出先后、能够推进的行动路径。

我不把自己定义成只讲知识的人。

我的价值更接近于：当事情已经发生、局面开始失控时，先判断真正的矛盾在哪里，再确定哪些信息必须补齐、哪些动作应该先做、哪些事情需要停止。

## 02. 经历形成的能力

- 有法院、法律相关、资产处置和金融创业的复合经历。
- 长期处理人与人、人与钱、人与业务之间已经发生的现实问题。
- 擅长从说法、关系、时间、利益和行动中找出关键矛盾。
- 擅长市场营销：定位、客户分层、内容获客、竞品研究与落地方案。
- 对复杂问题的偏好不是“给一句正确的话”，而是把局面还原、把选项排清、把下一步做实。

## 03. 我能解决的典型问题

### 现实问题的处置

- 债务、资产、合作、婚姻、关系、职场和经营中的信息不对称问题。
- 当事人情绪很强、事实很乱、又必须尽快做决定的局面。
- 需要从大量资料、聊天、公开信息、时间线和关系中重新建立判断框架的情况。

### 内容与增长

- 将真实问题变成有钩子、有判断、有行动顺序的短视频内容。
- 用 AIGC、程序化剪辑和固定资产，降低内容生产成本、提高复用效率。
- 围绕用户痛点、信息差和行动后果，做不生硬的内容转化。

### 项目与产品

- 从用户痛点、竞品、供应链、交付能力和市场入口反推产品定位。
- 用“小范围真实验证”代替一开始就堆满功能和投入。

## 04. 我的工作方法

```text
事实不全
  -> 先区分已知、未知和误判
  -> 再找到真正影响结果的人、钱、时间和关系
  -> 排出最先要处理的风险
  -> 设计沟通、推进、修复或退出的行动路径
  -> 用结果复盘，而不是只停在道理上
```

我更相信三件事：

1. 很多问题不是没有办法，而是关键事实还没有被看见。
2. 顺序错了，努力越多，损失可能越大。
3. 能解决问题的人，不一定说得最多，但必须知道下一步该做什么。

## 05. 与 AI 的协作方式

我把 AI 当作分析、整理、创作和执行的放大器，而不是替我做判断的“标准答案机器”。

- AI 负责：资料结构化、信息抽取、方案比较、文案迭代、视觉生产、自动化和项目归档。
- 我负责：判断真实利益、设定边界、识别风险、做关键选择并承担结果。
- 协作标准：先问清问题，再拆路径；先验证事实，再给结论；输出必须能落地。

常用工具包括 Codex、Obsidian、火山引擎及相关 AIGC 工具链。

## 07. 对外表达边界

- 不将自己包装成律师、调查专家、执法人员或其他持证专业人士。
- 内容以生活判断、信息整理、沟通协调和问题处置为主。
- 不承诺“必然找到”“保证回款”“一定解决”。
- 不使用或传播密码、验证码、Cookie、API Key、身份信息、银行卡信息等敏感认证资料。
- 涉及专业、法律、平台或人身风险的问题，必须明确事实边界和可验证路径。
